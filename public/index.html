PROJECT 03

SMS Spam Detection

Classifies SMS messages using TF-IDF and Multinomial Naive Bayes, comparing stemming and lemmatization pipelines.

WHAT IT DOES

  • Step-by-step NLP preprocessing
  • Bag-of-words and TF-IDF comparison
  • Confusion matrices and classification reports
  • Individual SMS and batch CSV analysis

Technology

Python · Streamlit · NLTK · Naive Bayes

System flow

Message → text preprocessing → TF-IDF → Naive Bayes → ham/spam

IMPLEMENTATION NOTES

The supplied notebook records 97.67% accuracy for stemming and 97.94% for lemmatization on its held-out split. These are saved notebook results, not a new validation run. The dataset contains 5,572 messages.

The Python application is supplied as downloadable source; it is not executed inside this static portfolio.
